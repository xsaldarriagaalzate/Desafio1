
# Juego Sweet Crush en C++

## Descripción

Este proyecto consiste en un juego tipo sweet crush desarrollado en C++. El programa utiliza un tablero de fichas donde se buscan combinaciones de tres o más fichas iguales para eliminarlas y obtener puntos.

En el proyecto se trabaja con memoria dinámica, punteros y almacenamiento de fichas utilizando 3 bits.

## Funciones principales

- Detectar combinaciones horizontales y verticales.
- Eliminar fichas, filas y columnas.
- Reorganizar el tablero después de las eliminaciones.
- Generar nuevas fichas.
- Procesar cascadas y calcular puntos.
- Manejar la memoria dinámica del tablero.

## Conceptos utilizados

- Punteros y arreglos dinámicos.
- Manejo de memoria con `new` y `delete`.
- Operaciones con bits.
- Funciones en C++.
- Detección de combinaciones.

## Objetivo

El objetivo es desarrollar un juego funcional y poner en práctica los conocimientos de C++, especialmente el manejo de memoria, los punteros y las operaciones con bits.
